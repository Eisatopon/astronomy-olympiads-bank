# Hipparchus – World Astronomy & Astrophysics Olympiads Bank

https://hipparchus.eisatopon.gr/ — astronomy and astrophysics olympiad problems (IOAA and more) in English with LaTeX. Statements only; no solutions. A project of eisatopon.gr, sister of the Pythagoras mathematics bank (https://eisatopon.github.io/national-olympiads-bank/).

This repository holds only the files the website loads.
